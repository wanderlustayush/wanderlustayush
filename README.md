## ⭐ Featured Project — VideoRAG

### 🎬 VideoRAG — AI-Powered Video Learning Platform

Ask anything about any YouTube video or uploaded file and get AI-powered answers with exact clickable timestamps.

**Live Demo:** [videorag.vercel.app](https://videorag.vercel.app) | **GitHub:** [videorag](https://github.com/wanderlustayush/videorag)

**Tech Used:**
- Whisper (faster-whisper) — Speech-to-text transcription
- ChromaDB — Vector database for semantic search
- Groq / Llama 3 — LLM for RAG-based Q&A
- FastAPI — Backend with background task processing
- React + Firebase — Frontend with authentication
- Vercel + Render — Deployment

**Highlights:**
- Full RAG pipeline — transcription → vector storage → LLM answering
- Clickable timestamp citations — jump to exact moment in video
- Supports YouTube URLs and local video file uploads
- Firebase authentication with Google and Email login
